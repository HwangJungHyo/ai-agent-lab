# 실습 증거 기록

- 회차 / 날짜 / 실행 ID:
- 관련 커밋:
- 상태: 계획 / 진행 / 완료 / 중단
- 목적: 무엇을 확인하려 했는가?
- 환경: OS, Python 경로·버전, 패키지·이미지 버전, 모델 ID
- 입력과 조건: 샘플 ID, 조사 시간 범위, 제한값
- 예상: 실행 전에 예상한 결과
- 변경: 바꾼 코드·설정과 이유
- 실행: 재현 명령과 실제 입출력
- 관측: 도구 호출·모델 호출 횟수, 시간, 사용량, 종료 사유
- Trace 참조: 비밀값이 포함되지 않은 식별자
- 판단: 증거로 어디까지 말할 수 있는가?
- 실패·미확인 범위:
- 다음 단계:

원본 증거에 키, 토큰, 고객 데이터가 포함되면 커밋 전에 제거합니다. 샘플 결과를 실제 환경 검증으로 표시하지 않습니다.
