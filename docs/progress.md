## 다음 시작점

2026-10-09 [모델 API 503 재시도](evidence/2026-10-09-model-retry.md): 별도 Linux 환경과 사용자 PC에서 HTTP 대역 검증 3개를 통과했다. 사용자 PC의 실제 Gemini 연결에서도 chain·graph + flaky를 확인했다. 실제 실행에서 503이 발생했는지와 HTTP 총 시도 횟수는 출력으로 확인할 수 없다.

1. [로컬 Qwen3.5 연결](evidence/2026-10-09-local-models.md), [요약 지시 비교](evidence/2026-10-09-local-summary.md), [필수 사실 코드 출력·모델 설명 분리](evidence/2026-10-09-facts-and-explanation.md)의 순서로 진행했다. 사용자 PC에서 --check-report 6개 PASS와 graph/separated의 flaky·empty·timeout을 확인했다. 코드의 필수 사실과 종료 경로는 예상과 일치했다. 모델 설명에는 부정확한 전제가 남았으므로 내용 정확성을 완료 처리하지 않는다. 문구 변경의 반복 효과를 측정하려면 같은 엔진·시나리오·설정으로 별도 비교한다.
2. 다음 실행 과제는 실제 관측 데이터 연결 조건 확인이다. observability-lab의 현재 가동 상태와 Loki 엔드포인트·접근 권한, 서비스 라벨, 조회 시간 범위·필터·반환 제한을 확인한다. 실제 데이터 수집·조회·에이전트 연결은 아직 미구현이다. 빈 결과·조회 실패·수집 지연·잘린 결과를 구분하고 원본 응답과 코드 사실 영역을 대조한다.
3. 전체 의존성 lock과 사용자 PC 기존 코드 대조는 재현성 과제로 남긴다. 패키지 5개 버전 출력은 전체 lock이 아니다.
4. 현재 단일 도구에서는 chain과 graph 모두 같은 정책을 구현했다. 상태 저장·재개·사람 승인 등의 요구가 생길 때 LangGraph의 추가 구성을 검토한다.
