## 다음 시작점

1. 모델 API 503 정책을 도구 재시도와 분리해 설계한다. 코드는 `max_retries=0`을 보존했다. SDK의 실제 HTTP 시도 횟수 의미는 설치 버전·소스 확인 후 기록한다.
2. chain + flaky를 확인한다. 필요하면 결정적 모델 대역으로 제어 흐름을 먼저 검증하되 실제 API 통합 증거와 구분한다.
3. PC 최신 코드와 복원본을 대조하고 설치 버전을 수집한다.
4. 실제 조회·체크포인트 등 후속 구현은 필요성과 장단점을 함께 설명한다.
